# Deployment Readiness

## Frontend: Vercel

`vercel.json` deploys the static `frontend/` directory. Set `FRONTEND_API_URL` in the Vercel project environment to the public API URL ending in `/api`, for example `https://api.example.com/api`.

The build writes that public value to `frontend/runtime-config.js`. It must never contain API keys, database URLs, or JWT secrets.

## Local PostgreSQL

For a local database, install Docker Desktop and start the supplied service:

```bash
docker compose up -d postgres
```

Then set the following values in `backend/.env`:

```env
DATABASE_URL=postgresql://lycan:lycan_local_only@127.0.0.1:5432/lycan_matcher?schema=public
JWT_SECRET=replace-with-a-long-random-local-secret
```

Run `npm run db:migrate`, `npm run db:seed`, and `npm run dev` from the repository root. The Docker password is deliberately local-only and must never be used for a hosted database.

## Backend: Render

`render.yaml` defines the Express service. Set the following values in Render:

- `DATABASE_URL`: PostgreSQL connection string from Neon or Supabase
- `FRONTEND_ORIGIN`: deployed Vercel origin, with no trailing slash
- `JWT_SECRET`: generated by Render or replaced with a long random secret
- `OPENAI_API_KEY`: optional; leave empty to use deterministic matching

Run Prisma migrations as a release step after the first database is created:

```bash
npm --prefix backend run prisma:migrate
npm --prefix backend run seed
```

## CV Privacy

CVs are personal data. The local upload directory is suitable only for development. Production deployment should replace local disk storage with private object storage, use signed download URLs, define a retention/deletion policy, and restrict access to the candidate and authorized recruiters.

## Production Checklist

- migrate PostgreSQL schema
- seed non-sensitive demo records only
- set production CORS origin
- run API tests
- run frontend build
- verify `/api/health` reports `database: connected`
- verify login, application status update, notification, and CV flows against deployed services
